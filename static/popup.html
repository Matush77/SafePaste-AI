Protection level

What it is
An English name-recognition model (DistilBERT, fine-tuned to find people, organisations and places), about 66 MB.
Where it comes from
Downloaded once from Hugging Face (huggingface.co) when you turn this on. SafePaste only accepts one fixed version of the model and checks every file against its known fingerprint (SHA-256) before using it.
Where it is kept
In this browser's cache for SafePaste, on your device. Turning the feature off keeps the download so it can be turned on again instantly; removing the extension deletes it.
How it is used
When you paste into a supported AI chat, the text is checked by the model on your device, together with the built-in rules. Pasted text is never sent to Hugging Face or anyone else. The download request contains no personal data, but like any download it shows your IP address to Hugging Face.
If it fails
If the model cannot load or answer in time, pastes are still redacted with the built-in rules, and the notice tells you so.
